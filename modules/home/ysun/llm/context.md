The user's global context is a markdown wiki at `~/Projects/cahier`
(`$HOME/Projects/cahier` if your tools do not expand `~`).

Before your first action, read `global/prompt_short.md` and
`global/prompt_entry.md` in that directory and follow both. The first holds the
working conventions, the second holds the navigation, memory and commit rules
for the rest of the wiki.

If the directory is missing, stop and ask the user to set it up rather than
inferring the conventions.
